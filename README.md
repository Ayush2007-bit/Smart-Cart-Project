# 🛒 Smart Cart – Unsupervised Learning

Smart Cart is a machine learning project that uses **Unsupervised Learning** techniques to analyze customer shopping behavior and discover meaningful customer groups.

## 📌 Project Overview

The project analyzes customer shopping data and applies clustering techniques to identify customers with similar purchasing behavior.

Unlike supervised learning, the model does not require a predefined target label. Instead, it discovers hidden patterns and customer segments directly from the available data.

## 🎯 Objectives

- Analyze customer shopping behavior
- Perform data preprocessing and exploratory data analysis
- Identify patterns in customer purchasing behavior
- Apply unsupervised machine learning
- Segment customers into meaningful groups
- Visualize customer clusters
- Understand different customer profiles

## 🛠️ Technologies Used

## 🤖 Machine Learning Technique

The project uses **Unsupervised Learning** for customer segmentation.

### Clustering

Clustering groups customers based on similarities in their shopping behavior.

The project can use techniques such as:

- K-Means Clustering
- Elbow Method
- Cluster Visualization
